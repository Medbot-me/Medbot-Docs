# Background Runs

When you want to process multiple folders in the background, processing them one at a time can take too long. Instead, you can use the Background Run feature to process them in the background, even when not using the app.

To use background runs, visit [medbot.me/agents](https://www.medbot.me/agents) and click the Background Run icon under Actions, as shown below.

![Background Run](/images/background-run.png)
***Background Run** icon under Actions*

Clicking this icon will take you to the background run page. You can follow the following steps to start a background run.
1. Select folders that you want to process
2. Click the `Start processing` button

![Background Run Page](/images/bg-run.png)
*Steps to start a background run*

A progress bar showing the progress of your latest background run will be shown once a run starts. You can also see your past background runs in this page.

![Background Run Progress](/images/bg-run-progress.png)
*Background run progress*

The `Event ID` field of a background run will be filled in once it's complete.

*Note: You can only have **one** background run running at a time. Once you select a number of folders and start processing, you will have to wait for this run to complete before you can start a new one.*
