# Background Runs

A background run processes many patients at once and keeps going when you leave the app. Use it to run an agent over a dataset, or a cohort within one.

## Starting a background run

1. Open the agent and click **Run**.
2. Under **Choose patients**, pick a dataset and select the patients to process (**All** selects every patient shown), then click **Use &lt;n&gt; patients**.
3. Set **Run mode** to **Background**, choose the **Processing** (**With algorithm** follows the agent's workflow), and click **Run**.

Medbot confirms that background runs have started, one per patient.

## Following a run

- The agent's **Agent Runs** tab lists every call, with its patient, mode, status and who started it. Retry failed calls, cancel running ones, or open a call to see its output.
- **View background runs** on the Agents page lists all your background calls across agents, with the agent used, the patient, the event id and the status.
- When every patient in the run has finished, you get a notification such as *&lt;agent&gt; · background run finished: 42 of 44 patients completed, 2 failed*, which opens the agent's **Agent Runs** tab. See [Notifications](/docs/agents#notifications).

Validation runs are background runs too. They run the agent's validation dataset and are scored when they finish; see [Validation](/docs/agents/validation).
