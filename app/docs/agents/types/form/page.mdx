# Form Agents

Form agents provide a convenient way to fill out medical forms based on a patient record. You can use them on individual notes in the workspace.

## Creating Form Agents
To create a form agent, choose **A form the clinician fills in** under **How the agent is called** in step 2 of the [agent wizard](/docs/agents/create-an-agent#how-the-agent-is-called).

## Using Form Agents
### From the workspace
To use form agents from the [workspace](/docs/workspace), open a note, select the **Agents** tab in the **AI** panel on the right and choose **Run** on a form agent (each agent also has a **Default** / **Algo** processing choice). A dialog opens with the agent's name, where you choose the form to fill in and select **Apply Agent**.

The form can be a PDF, Word (.docx), Excel (.xlsx) or CSV file. Medbot reads the form's text ("Reading the form…", then "Extracted the form's text."); only the first 200,000 characters are used.

*Form Agent Dialog for the default **Insurance Form Processor** agent in the Workspace*

Once the agent has finished processing, select **Click here to view result** to go to the results page.
