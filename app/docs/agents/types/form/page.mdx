# Form Agents

Form agents provide a convenient way to fill out medical forms based on a patient record. You can use them on individual notes in the workspace, or on an entire folder in the file browser.

## Creating Form Agents
To create a form agent, simply select the `Process forms` checkbox while creating an agent.

## Using Form Agents
### From the workspace
To use form agents from the [workspace](/docs/workspace), open a note, select the My Agents tab and click `Run` on a form agent. You will be presented with a dialog as shown below where you must select a form to be filled out by the agent.

![Form Agent Dialog](/images/form-agent.png)
*Form Agent Dialog for the default **Insurance Form Processor** agent in the Workspace*

Once the agent has finished processing, click the `Click here to view result` button to go to the results page.

### From the file browser
The file browser can be used to apply a form agent to an entire folder. Click the `Agents` button under `Actions` in the file browser as shown below.

!['Agents' Action](/images/agents-action.png)
***Agents** action in the file browser*

This will open up a dialog where you can select the form agent you want to use and upload a form. The agent will process the folder you selected to fill out the uploaded form.
