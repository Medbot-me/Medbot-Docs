# Non-Form Agents

Non-Form agents can be used for a variety of purposes. You can define what a non-form agent does using the `Algorithm` and `System Instructions` fields while creating an agent.

## Creating Non-Form Agents
While creating an agent, not selecting the `Process forms` checkbox will create a non-form agent.

## Using Non-Form Agents
### From the workspace
Non-Form Agents can be used from the sidebar or from the [bubble menu](/docs/workspace/editor#bubble-menu) in the [workspace](/docs/workspace), depending on the type of the agent. In the context of the workspace, there are two types of non-form agents:
1. Full-text agents
2. Selection agents

Full-text agents process the whole content of an open note in the workspace. They can be used from the My Agents tab in the workspace sidebar. You only need to have the note that you want to process open in the workspace to use a full-text agent.

Selection agents work by processing a selection from an open note in the workspace. They can be used from the bubble menu. You need to select text in the workspace to use a selection agent.

The image below shows (1) selection agents in the bubble menu and (2) full-text agents in the My Agents tab of the sidebar.

![Workspace Agents](/images/workspace-agents.png)

### From the file browser
Non-form agents can be used to process notes in a folder in a similar manner to [form agents](/docs/agents/types/form#from-the-file-browser). Visit [medbot.me/notes](https://www.medbot.me/notes) and click the `Agents` button under `Actions` on a folder of your choice. This will bring up a dialog where you can select the agent you want to use.

The results will be shown in the dialog itself and will be according to the System Instructions and Algorithm fields you defined while creating the agent.
