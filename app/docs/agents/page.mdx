# Introduction

Agents are a central component of the Medbot AI features. They facilitate quick processing of notes, and can be used for a variety of purposes such as filling out forms and detecting inconsistencies in diagnosis/treatment recommendations.

### Creating agents
To create agents, fill out the form at [medbot.me/agents/new](https://www.medbot.me/agents/new). The table below describes each field in the agent creation form.

| Field                            | Description                                                                     | Affects agent behavior |
| -------------------------------- | ------------------------------------------------------------------------------- | ---------------------- | 
| Agent Name                       | The name of the agent to be created.                                            | No                     |
| Description                      | A descriptive text describing the agent's purpose.                              | No                     |
| System Instructions              | General instructions the agent must follow while executing a task.              | Yes                    |
| Define your algorithm<sup>1</sup>| Step-by-step instructions the agent must follow to determine its response.      | Yes                    |
| Agent Category                   | Type of the agent to be created.                                                | Yes                    |
| Select Model                     | LLM Model to be used for the agent.                                             | Yes                    |
| Define fields used by your agent | Fields to be returned by the agent in its JSON response.                        | Yes                    |
| Process whole note content       | Whether to process all contents of the open note in the workspace.              | Yes                    |
| Use Database tools               | Whether to use database tools. To view the details about Database tools [Click Here](#database-tools) | Yes |
| Make this agent public           | Whether to make the agent available to the other members of your organization. | No                     |
| Process forms                    | Whether the agent is meant to process forms.                                   | Yes                    |

1. See [this](#) section on how to define an agent algorithm.

### Agent Types
Agents on Medbot can be used for any of the many agentic features available. However, agents can broadly be categorized into the following types.
1. [Form Agents](/docs/agents/types/form)
2. [Non-Form Agents](/docs/agents/types/non-form)
3. [Deep Research Agents](/docs/agents/types/deep-research)

Please visit their respective pages to learn more about them.

### Agent Visibility

Agents in Medbot can be categorized as **Private, Public, Default, or Shared**:

#### 1. Private Agents

These are agents you create and choose not to make public.
**Access:** Only you can access them.

#### 2. Public Agents

These are agents made public by other Medbot users.

* You can browse them in the **"Public Agents"** tab on the Agents page: https://www.medbot.me/agents
* To make your own agent public, go to its edit page and enable the **"Make this agent public"** checkbox.

#### 3. Default Agents

These are agents managed by your administrator (or by Medbot).

* You can **view and use** them to process folders
* You **cannot edit or delete** them

#### 4. Shared Agents

These are agents shared with you by other users via your email address.

* You can find them in the **"Shared with me"** tab on the Agents page: https://www.medbot.me/agents
* You can share your own agents using the context menu on any of your agents

> **Note:** You cannot share an agent that is already public, since it is already accessible to everyone.

### Background runs
Each agent you create can be used to process notes in bulk as a background process that continues working even when you leave the app. You can learn more about it [here](/docs/agents/background-runs).

### Agent Demo
The Agent Demo feature allows you to generate a sample note, use your own note, or browse your directory of notes to select a number of notes to be processed by the agent. This allows you to verify your agent's behavior in a temporary environment.

#### Email Tool

The **Email Tool** allows agents to send emails during execution.


##### Email Tool Behavior

| Configuration | Result |
| --- | --- |
| Email Tool disabled | No email is sent, even if the agent is instructed to send one. |
| Email Tool enabled, no template selected | A raw email is sent to the recipient. |
| Email Tool enabled with a template selected | A formatted email is generated using the selected template. |
