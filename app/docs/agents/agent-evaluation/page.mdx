## Agents Demo

Medbot provides a comprehensive evaluation of your agents by combining LLM-as-a-judge techniques with human-in-the-loop validation.
This approach enables accurate assessment and measurement of agent performance.
Using these evaluations, Medbot calculates key performance metrics such as accuracy, sensitivity, specificity, positive predictive value (PPV), and negative predictive value (NPV).

To evaluate your agents:

1. Go to homepage and navigate to Agents tab from the sidebar.

2. Click on the eye icon under "Actions" column from the table.
   ![DeepResearch Workflow](/images/agent-evaluation/eval1.png)

3. You will see the agent's demo page where you can evaluate your agent outputs.
   ![DeepResearch Workflow](/images/agent-evaluation/image1.png)

4. Click on the "Evaluate Results" button from the agent demo page.

5. You will be navigated to the evaluation page where you can see the past agent calls as below:
   ![DeepResearch Workflow](/images/agent-evaluation/eval9.png)

6. Analyse the agent's output and label it as correct or incorrect and enter the "Expected Ground Truth / Comments" using "Label Output" button.
   ![DeepResearch Workflow](/images/agent-evaluation/eval18.png)

7. Click on the "Use LLM as Judge" button to label the output using an llm.You will see a detailed llm's report as below:
   ![DeepResearch Workflow](/images/agent-evaluation/eval11.png)

8. You call view your labels using the eye icon under the "Actions" tab.
   ![DeepResearch Workflow](/images/agent-evaluation/image.png)

9. Follow step 6 and 7 for all the agent calls that you want to evaluate.

10. You will see a detailed evaluation classification report as below.
    ![DeepResearch Workflow](/images/agent-evaluation/eval13.png)

11. Other than "classification" output type, select the "Other" option from the dropdown of Output Type.
    ![DeepResearch Workflow](/images/agent-evaluation/eval14.png)

12. Analyse the agent's output and evaluate on the basis of "Reasoning", "Accuracy" and "Completeness" and enter "Expected Ground Truth / Comments" using "Label Output" button.
    ![DeepResearch Workflow](/images/agent-evaluation/eval15.png)

13. You can view the evaluation using the eye icon under the "Actions" tab.
    ![DeepResearch Workflow](/images/agent-evaluation/eval16.png)

14. Follow step 12 for all the agent calls that you want to evaluate.

15. You will see a detailed evaluation report as below:
    ![DeepResearch Workflow](/images/agent-evaluation/eval17.png)
