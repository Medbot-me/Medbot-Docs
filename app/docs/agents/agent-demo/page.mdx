## Agents Demo

Medbot provides an interface where you can run your note agents on sample notes from workspace or a demo note.

To try this out:

1. Go to homepage and navigate to Agents tab from the sidebar.

2. Click on the eye icon under "Actions" column from the table.
   ![DeepResearch Workflow](/images/agent-evaluation/eval1.png)

3. You will see the agent's demo page where you can use a demo note to run your agent.

4. To run the agent with an algorithm, ensure the algorithm is properly defined in the agent's edit section.

5. Click the "Generate Plan" button to visualize and save the agent's plan based on the defined algorithm.
   ![DeepResearch Workflow](/images/SavePlan.png)

6. Adjust the visualization orientation between vertical (default) and horizontal using the orientation button in the visualization canvas for your preferred view.

7. If a plan is already saved, you can easily review and modify it directly through the visualization interface, ensuring your workflow remains flexible and up to date.

8. Generate a sample note using "Generate Sample Note" button.
   ![DeepResearch Workflow](/images/agent-evaluation/eval2.png)

9. You can also select a note from your workspace using the "Select Files" button.
   ![DeepResearch Workflow](/images/agent-evaluation/eval3.png)

10. You can run the agent on your demo note using three options which you can see if you click on the Run Agent dropdown.
    Click either of the three options. You can run the agent with or without algorithm. You can also run the agent in the background using "Run Backgroung process" option.
    Visit [Background Runs](/docs/agents/background-runs) to learn more about background runs.
    ![DeepResearch Workflow](/images/agent-evaluation/eval4.png)
