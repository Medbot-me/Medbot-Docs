
## Evaluate agents' results

The agent evaluation page allows you to review each article independently.
You can see the title of the research paper, the decision of the agent (which is found using majority voting if you used multiple agents to process your articles),
along with the justifications for the decision. This step allows the results to be verified by the user.
Users can search the results by the title and can also download the results if they prefer using the "Download Results" button. 
This page also has multiple filters that you can use to analyse your research results. You can filter the articles by the publication date, user comments, and included/excluded articles.
In addition you can define more agents and process the final results further based on what you need.
