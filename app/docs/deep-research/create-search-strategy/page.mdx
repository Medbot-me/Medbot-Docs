## Create search strategies

Search strategies are search strings used to gather research papers for a specific research question. Each strategy has a strategy name, a search database (currently we only support pubmed), and a search query string
which is generated based on the research question, search database, search start date and end date.

In order to generate a search strategy:

![DeepResearch Workflow](/images/image6.png)

1. Click "New Search Strategy"

![DeepResearch Workflow](/images/image7.png)

2. Enter a name
3. Select search database
4. Select search start and end date
5. Click Generate Search Strategy
6. Click Update Strategy
