## Default Agents

The deepresearch feature has multiple default agents working to automate your tasks. It includes:

1. Default Inclusion Exclusion Agent
This agent takes your search results along with the inclusion and exclusion criteria and screens each article 
to decide if it should be included or excluded based on the criteria.

2. Search Strategy Generator
This agent generates the search string required to search the database for a specific research question.

3. Default Inclusion Exclusion Criteria Generator
This agent generates inclusion and exclusion criteria for the research question.

4. Process Inclusion Exclusion Results
This agent answers your research question based on the articles that are included by the inclusion exclusion agents.

### The Orchesrator

All the agents above are exposed as tools to the orchestrator agent. The workflow  for the orchestrator is given below:

1. The orchestrator decides which agent it needs to call based on user requirements along with reasons for selecting that agent.
2. The default agents are exposed as tools to the orchestrator.
3. The orchestrator executes the tool.
