# Advanced

## Custom settings

You can customize the behavior of the [autocomplete](/docs/workspace/editor#autocomplete) feature and the [text refining](/docs/workspace/editor#text-refining) feature by visiting [medbot.me/settings](https://www.medbot.me/settings).

### Autocomplete settings

The following table describes each autocomplete setting.

| Setting                            | Description                                                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Enabled                            | Whether to enable autocomplete.                                                                              |
| Previous Word Length               | The number of words immediately before the cursor that autocomplete AI will process to suggest continuation. |
| Suggestion Debounce Length (ms)    | The amount of inactivity time, in milliseconds, before the autocomplete displays suggestions.                |
| Autocomplete Length (words)        | Number of words that autocomplete will suggest as continuation.                                              |
| Model                              | The LLM model to use for autocomplete.                                                                       |
| Temperature (0-1)                  | Temperature parameter for the LLM model.                                                                     |
| Create Embeddings for Autocomplete | Whether to create embeddings for autocomplete.                                                               |

### Text Refining settings

These settings apply to the [Quick Refine](/docs/workspace/editor#text-refining) feature in the workspace bubble menu. Following is a description of each available setting.

| Setting        | Description                                         |
| -------------- | --------------------------------------------------- | --- |
| Default Prompt | The prompt to be used for the Quick Refine feature. |     |
| Default Model  | The model to be used for the Quick Refine feature.  |

### Account Settings

Your account settings allow you to manage your personal and professional information associated with your Medbot account. Keeping these details up to date ensures a personalized and secure experience. The table below outlines each available setting and its purpose:

| Setting    | Description                                                 |
| ---------- | ----------------------------------------------------------- |
| First Name | Edit your first name as it appears on your account.         |
| Last Name  | Edit your last name as it appears on your account.          |
| Email      | View your registered email address. This cannot be changed. |
| Country    | Specify or update your country of residence.                |
| Occupation | Indicate your current professional occupation.              |
| Practice   | Provide or update your practice or area of specialization.  |
