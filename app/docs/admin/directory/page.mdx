# Provider Directory

> **For Medbot platform administrators only** (admin and superadmin).

The directory lists organisations and services that are not on Medbot yet. Patients can find them and ask to be referred, and their staff can [claim them](/docs/getting-started/claim-an-organisation). Open it from **Directory** in the [Admin Panel](/docs/admin).

## Browse

The tabs filter the list: **All**, **Unclaimed**, **Claim under review**, **Claimed** and **Hidden**. Search with "Search by name, postal code or specialty". Open a listing to see and edit it.

## Add a listing

1. Select **New listing**. The **New directory listing** dialog opens.
2. Fill in **Name**, **Slug** (for example bukit-clinic), **Country**, **Address**, **Postal code**, **Phone**, **Referral email**, **Website**, **Specialties** and **Description**.
3. Select **Create listing**.

The **Referral email** is where referral requests for this provider are sent automatically.

## Change or remove a listing

On a listing you can:

- **Edit** it (the dialog is headed with the listing's name) and select **Save**.
- **Hide** it so patients no longer see it, and **Restore** it later.
- **Delete** it. Medbot asks "Delete &lt;name&gt;?" to confirm. A listing that a referral or claim refers to cannot be deleted: hide it instead.

## Services on a listing

A listing can also have services of its own. In the listing's services card, choose **Add a service** (or **Edit service**) and fill in **Name**, **Specialty**, **How care is delivered**, **Referral email** (if blank, the organisation's is used) and **Description**. Services can also be hidden, restored or deleted. A badge reads **No referrals** until someone asks for it.
