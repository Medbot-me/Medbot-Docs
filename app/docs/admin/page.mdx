# Platform Administration

> **For Medbot platform administrators only.** These pages describe the Admin Panel used by the Medbot team to run the platform. If you are a clinician or clinic staff member, you will not see it and can skip this section. Organisation admins manage their own organisation under **Organisation settings** and **Members** instead.

## Opening the Admin Panel

Platform administrators have a platform role of **admin** or **superadmin**. This is separate from any role you hold in an organisation.

1. Open **Settings** from the account menu.
2. Select **Admin Panel** at the top right.

The panel's sidebar shows **Platform admin** or **Platform superadmin** under its title. Select **Back to Settings** to leave. On a phone, the sections appear as a scrolling tab strip. If you are not an administrator, the panel redirects you to Home.

## Sections

Sections marked (superadmin) are shown to superadmins only.

| Group | Section | What it is for |
| --- | --- | --- |
| Platform | **Overview** | Totals for users, agents and bug reports, and agent usage. |
| | **User Management** (superadmin) | Users, their credits (**Top up credits**) and **Usage**. See [AI Usage & Credits](/docs/ai-usage#for-administrators). |
| | **Identity Cleanup** (superadmin) | Platform tool for cleaning up user identities. |
| | **Caregiver Access** | Platform tool for caregiver access. |
| Organisations & services | **Organisations** | All organisations. Filter by **All**, **Active**, **Offboarded**, **Hosted** or **Self-managed**; search with "Search by name or slug". |
| | **Services** | A read-only list of services. Filter by **All**, **Published**, **Draft** or **Archived**; search with "Search by service, specialty or organisation". Open a service to manage it on its own page. |
| | **Directory** | Providers not yet on Medbot. See [Provider Directory](/docs/admin/directory). |
| | **Referral requests** | Patients' requests to be referred. See [Referral Requests](/docs/admin/referral-requests). |
| | **Claims** (superadmin) | Claims on directory listings. See [Claims Review](/docs/admin/claims). |
| AI & content | **Templates**, **Tools**, **Agents** | Shared templates, tools and agents. |
| | **Models**, **Audio Models**, **Realtime Models** | Which AI models are available to everyone. The platform administrator chooses these; users pick from what is listed. Models that can read images show an **Images** badge. |
| | **Vision Tasks** | Which model reads photos and files for each image task, such as health-log photos and uploaded documents. See [Vision Tasks](/docs/admin/vision-tasks). |
| | **Care Context Prompts**, **Sample Notes** | Prompts and sample notes used by care features. |
| Support | **Patient Channels**, **Bug Reports** | Patient messaging channels and reports sent with **Report a bug**. |
