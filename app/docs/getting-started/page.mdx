# Getting Started

## Create an account

To create an account, head over to [medbot.me/login](https://www.medbot.me/login). You have the option to create your account using an email address and a password, or log-in using a Google account.

## Onboarding

Upon sign-up (or first log-in using a Google account), you will be presented with an onboarding setup. Here, you can customize your profile before you start using Medbot. You can <br/> (1) Confirm you email address and name. <br /> (2) Confirm your country and professional background.<br/> (3) Select default clinical notes to import. <br/> (4) Select default agents to load.
