# Getting Started

## Create an account

To create an account, head over to [medbot.me/login](https://www.medbot.me/login). You have the option to create your account using an email address and a password, or log-in using a Google account.

## Onboarding

Upon sign-up (or first log-in using a Google account), you will be presented with an onboarding setup. Here, you can customize your profile before you start using Medbot. You can (1) confirm you email address and name, (2) select default clinical notes to import, and (3) select default agents to load.
