# Desktop & Mobile Apps

Medbot is available in three places: the Medbot app on the web, a desktop app, and a mobile app. All three use the same account and show the same agents, notes, templates and research, so work you start in one is there in the others.

- **The Medbot app on the web** ([medbot.me](https://www.medbot.me)) is the full product. Use it for everything, including organisation features, the admin panel and setting up datasets.
- **The desktop app** is for working at a computer without a browser tab: writing notes, running agents and doing Deep Research in its own window. It can also keep your notes for working offline, and use AI models you run yourself. See [Desktop app](/docs/desktop-and-mobile/desktop).
- **The mobile app** is for checking in on the move: reading and editing notes, running agents on typed text, following Deep Research reviews, and getting your Inbox updates. See [Mobile app](/docs/desktop-and-mobile/mobile).

Both apps cover your personal workspace. Anything that belongs to an organisation stays on the web.

## What each app can do

| | Web | Desktop | Mobile |
| --- | --- | --- | --- |
| Home, Agents, Notes, Deep Research | Yes | Yes | Yes |
| Templates and Clinical Resources | Yes | Yes | Yes |
| Datasets | Yes | Yes | Opens on the web |
| AI in the note editor | Yes | Yes | No |
| Running a workflow on dataset patients | Yes | Yes | No |
| Background runs | Yes | Yes | No |
| Inbox | Yes | No | Yes |
| Notifications | In the Inbox | No | Phone notifications |
| Settings, AI usage, My account | Yes | Yes | No |
| Report a bug | Yes | Yes | No |
| Organisation features, admin panel, invitations | Yes | No | No |
| Working offline | No | Notes and folders to read and edit, datasets and resources to read, once you turn it on | Saved lists to read only |
| Updates | Always the latest version | Updates itself, on the stable or beta channel | See [Mobile app](/docs/desktop-and-mobile/mobile#getting-the-app) |
| Local AI models (Ollama, llama-server) | No | Yes, for chat and agent runs | No |
| Sign in | Email code, password or Google | Through your web browser | Password or Google |
| Create a new account | Yes | Yes, in your web browser | No |

## How to get the apps

Neither app is available to download publicly yet. There is no store listing or download page. Your Medbot administrator will tell you how to install an app while it is in early access.

Once installed, sign in with the account you already use on the web. The desktop app signs you in through your web browser. To create an account first, see [Getting started](/docs/getting-started).

## Taking clinical photos

Clinical photos are not taken in the mobile app. They are taken in the Medbot CMS in your phone's browser, which you can add to your home screen. See [Clinical photos](/cms/clinical-photos).
