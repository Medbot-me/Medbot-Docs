# Setup Resources

1. Select **Clinical Resources** in the sidebar. (It is in your **Personal** space; if you are inside an organisation, switch to **Personal** first.) Your resources are listed with their **Title**, **Status**, **Description** and **Attachment**.

2. Select **Create New Resource**.
3. Enter a **Title** (required) and, if you like, a **Description**. Choose the file: PDF, Word (.docx), Excel (.xlsx) or CSV, up to 25 MB (Excel 10 MB, CSV 5 MB).

<ImageZoom src="/images/docs/clinical-resources/01-upload-form.png" alt="The Create Resource form with a title, a description and a CSV file chosen, and the supported formats and size limits" />

4. Select **Upload Resource** ("Uploading…"). You are taken to the resource page.
5. Wait for the status to change from **Waiting to process** to **Processing…** to **Ready**. This usually takes a short while; larger documents take longer.

6. Optional: look through the **Resource sections** table (ID, Order, Section Header, Content, Actions) to check the document was read correctly.

That's it. Your agents can now use the resource as a tool, and you can refer to it from the **Resources** tab in the [workspace](/docs/workspace).

## Managing a resource

On the resource page:

- **Reprocess** runs the reading again, for example after a failure ("Reprocessing started").
- **Restart** deletes all the sections and starts again. It asks you to confirm because it cannot be undone.
- **Delete** removes the resource.
- **View resource** (PDF and CSV) or **Download** (Word and Excel) opens the original file.

In the list, the actions menu on each row has **View**, **Edit** (change the title or description) and **Delete**. Search the list by title.

## If it does not upload

Medbot explains why a file is refused, for example "Older Word and Excel files (.doc, .xls) aren't supported. Save it as .docx or .xlsx and upload it again." or "Upload a PDF, Word (.docx), Excel (.xlsx) or CSV file."
