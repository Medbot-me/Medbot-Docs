# Program Agents

Program agents are the AI agents you author to work on behalf of (or alongside) a care role, on the program's **Agents** tab. An agent is never a person — it stands in for, or assists, whoever is currently covering that role.

## Creating an agent

Click **Add agent** and fill in:

- **Name** — e.g. "Dietitian agent".
- **Care role** — which role this agent is scoped to (Consultant, Clinic nurse, PSA, Dietitian, Care coordinator, Pharmacist, or the special **Patient** role — see below).
- **Status** — Active or Inactive.
- **Preferred LLM** — the org default, or a specific model.
- **Tools** — a checklist of what this agent is allowed to call while it runs (e.g. messaging a patient over Twilio, choosing SMS or WhatsApp per call). A staff-role agent can also be given freeform **Other skills** (comma-separated identifiers) for anything not in the standard checklist.
- **Description** — a short summary of what the agent does.
- **Agent markdown** — the system prompt / instructions, in markdown.

Click **Add agent** to save. **Edit** and **Delete** work the same way from each row's actions.

## The `Patient` care role

Selecting **Patient** as the care role turns this into a **patient-facing** agent (badged "Patient-facing" in the table): the tool checklist switches to the smaller patient-agent tool set (appointments, clinical resources, triage, hand-off — never a raw "send message" tool or email), and the markdown field gets patient-agent-specific placeholder guidance. A fixed platform safety preamble (identity disclosure, scope limits, the emergency instruction) is always layered on top of whatever you write here and can't be removed by it.

Authoring a `Patient`-role agent doesn't make it live on its own — you still need to **bind** it in the program's Settings tab. See [Patient Agent](/docs/care-programs/patient-agent) for the full picture.

## Running a staff-role agent

Each staff-role agent's row has a **Run** button. In the dialog:

1. **Who to run against** — the entire cohort, or a hand-picked subset (searchable patient list with checkboxes).
2. **When** — **Run now**, **Schedule for later** (pick a date/time), or **Repeat daily** (pick a time of day, in UTC — runs every day until you cancel the schedule).
3. Click **Run now** / **Schedule run** / **Start daily schedule**.

A `Patient`-role agent doesn't get a Run button — it's reactive by design (it only ever replies to a message the patient sent) and gets a **Preview chat** button instead; see [Patient Agent](/docs/care-programs/patient-agent#preview-chat).

## Agent runs and schedules

Back on the Agents tab (below the agent list):

- **Agent runs** — a history of every run against this program's cohort, whether started manually or by a schedule.
- **Daily agent schedules** — every "Repeat daily" schedule currently active, with the agent and time; cancel one from here.

## Bound patient agent indicator

If a `Patient`-role agent is currently bound as the program's live patient agent (via Settings), its row carries a **Bound** badge. Deleting a bound agent is allowed but warns you first — it turns off patient chat for the program until a new agent is bound in Settings.
