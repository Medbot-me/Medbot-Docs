# Service Registry (Developers)

`@repo/smartcms-contract` (`packages/smartcms-contract/src/service-types.ts`) lists all **56** SmartCMS service types from section 4 of the SmartCMS Interface Specification v1.8.8. Every other part of the integration looks services up here.

```ts
import { serviceBySn, serviceByRoute, serviceByWireType } from '@repo/smartcms-contract';

const balance = serviceBySn(1); // chasAnnualBalanceEnquiry
```

## What each entry carries

| Field | Meaning |
| --- | --- |
| `sn` | The specification's serial number, 1 to 56. |
| `serviceType` | The catalog name, exactly as the specification spells it. |
| `wireServiceType` | The value actually sent in the control header and the `ServiceType` header. Equal to `serviceType` except for S/N 54 and 55. |
| `route` | The path under the gateway base URL. `null` only for S/N 25, whose route the specification leaves blank; the client refuses to call it. |
| `format` | `xml` or `json`. |
| `envelope` | The default wrapper: `scg-json` for JSON services, `scg-xml` for XML ones. It can be overridden per route with `SMARTCMS_ENVELOPE_OVERRIDES`. |
| `legacyEnvelopeCandidate` | True for S/N 1 to 15, which also have an older AP481 envelope form. |
| `group` | The entitlement group. Where a module exists, the group has the module's name. |
| `phase` | Delivery phase: **P0** platform, **P1** CHAS and MHCP subsidies, **P2** CDMP, **P3** registries and NEHR contribution, **P4** Healthier SG, **PM** an opt-in module outside the CHAS Badge, **X** out of scope, **L** legacy or retired. |
| `kind` | `enquiry` when the call changes no remote state, otherwise `submission`. |
| `safeToRetry` | True exactly for enquiries. |

> **Do not correct the spelling.** Names and routes are copied exactly, misspellings included (`submisssion/hsg/iquitjourney`, `putReconcillationFile`, `getPaginatedReferralByInstituion`). The gateway routes on these strings, and a test compares the list against a transcription of the specification.

A service can only be called when its group belongs to a module the organisation subscribes to and the location is entitled to it (see [Gateway](/cms/smartcms/gateway#entitlements)). Groups with no module (NEHR, CHAS_DENTAL, ALPS, PSS, LEGACY) cannot be called at all today. S/N 7, the clinic accreditation status query, is the one planned for a location's connection test.

## Other contract exports

| Module | What it provides |
| --- | --- |
| `envelope.ts` | Zod schemas for the control header, `SCG_RequestInfo` and `SCG_ResponseInfo` (strict on documented fields, passing unknown keys through); `SCG_STATUS_CODES` with HTTP status, error type and retry flag; `formatMsgDateTime` / `parseMsgDateTime` for Singapore-time timestamps. |
| `modules.ts` | `SMARTCMS_MODULES` (label, description, badge, status, service groups, "needs" chips, presets), `modulesForPreset('gp-starter')` and `SMARTCMS_BADGE_LABELS`. See [Modules & Gating](/cms/smartcms/modules). |
| `vocab.ts` | Submission states, actor kinds (member, agent, job), gateway outcome kinds, business-error categories and entitlement environments (`off`, `uat`, `prod`). |
| `codesets/` | 18 MHCP code tables and 6 HSAR ValueSet 7.3 sets, with date-aware `lookup(setId, code, onDate)` and `activeEntries(setId, onDate)`. |
| `fhir-urls.ts` | `urn:gov:sg:nric` and Medbot's `http://medbot.me/fhir/.../smartcms-*` StructureDefinition, CodeSystem and NamingSystem URLs. |
| `schema-version.ts` | `SCHEMA_VERSION`, the version of the knowledge base the contract was transcribed from (`kb-2026-09`). |
| `dto/` | Request and response shapes for upcoming endpoints (CHAS verification, the claims queue, location settings). Skeletons only. |

Run the package's tests with `pnpm --filter @repo/smartcms-contract test`.
